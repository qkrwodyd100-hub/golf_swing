# Yardage Book 데이터 안내 (README_DATA.md)

## 핵심 원칙

- 목적은 디테일한 공략이며, **부정확하거나 섬세하지 못한 정보는 없는 것만 못하다.**
- 실측 확인 전에는 그럴듯한 수치를 절대 입력하지 않는다. 미확인 항목은 `0`·빈값·빈 배열로 두고, UI는 '미입력'으로 표시한다.

## 수록 범위

- **실제 데이터**: 7개 충남 클럽의 **클럽명/코스명/지역**만 디렉토리 정보로 수록
  (백제CC, 솔라고CC, 천안상록CC, 예미지CC, 링스CC, 골든베이CC, 아름다운CC).
  코스 하위 9홀 구성명(예: 솔라고 "라고/솔/밸리")은 공개 안내 기준의 명칭이며,
  홀별 거리·핸디캡·파·전략은 포함하지 않습니다.
- **예시 데이터**: `data/courses.json` → `holes["solago:라고"]`의 **1~3번 홀**은
  `sample: true`인 예시 틀입니다. 거리·파·핸디캡·전략 문구는 전부 비워져 있으며
  실제 코스 데이터가 아닙니다.
- 그 외 모든 클럽/코스/홀은 데이터 없음(미입력) 상태로 표시됩니다.

## 홀 정보 상태 (UI 표시 규칙)

| 상태 | 뱃지 색 | 의미 |
|---|---|---|
| 미입력 | 회색 | 홀 데이터 없음. 거리 대신 "데이터 미입력" 표시 |
| 예시 | 노랑 | `sample: true`. 실측이 아닌 틀. 빈 항목은 '미입력'으로 표시 |
| 실측확인 | 초록 | `sample: false` + 근거 확보. 실측 수치 표시 |

- 홀 선택 탭의 점 색(회색/노랑/초록)으로 상태를 구분합니다.
- 개략도에는 항상 **'개략도(예시)'** 라벨과 **'위치 예시이며 실제와 다름'** 문구를 표시합니다.
- 미확인 홀의 개략도는 티/그린/핀 개념만 그리며, 해저드 위치는 그리지 않고 '미확인'으로 표시합니다.
- 실사진이 없는 홀은 **'실측 사진 없음'**으로 표시합니다.

## 실제 숫자 추가 방법

1. `data/courses.json`의 `holes`에 `"<clubId>:<코스명>"` 키를 추가합니다.
2. `_template` 항목을 복사해 홀 번호(`"1"`~`"18"`)별로 채웁니다.
3. 미확인 항목은 `0`·`""`·`[]` 그대로 둡니다(추측 입력 금지).
4. `npm run build`로 빌드가 깨지지 않는지 확인합니다.

## 실측확인(`sample: false`) 전환 절차

`sample`을 `false`로 바꾸는 것은 "이 홀 수치를 실측으로 보증한다"는 의미이므로,
반드시 아래 근거를 확보한 뒤에만 변경합니다.

1. 근거 확보 (둘 중 하나 이상):
   - 해당 홀 스코어카드 사진 (파·핸디캡·티별 거리 확인 가능)
   - 공식 코스 가이드 / 공식 야디지북 사진 (홀 배치·해저드 위치 확인 가능)
2. 근거 사진 파일명을 홀 편집자(또는 PR 본문)에 기록합니다.
   예: `evidence/solago-라고-1-scorecard.jpg`
3. `diagram.confirmed`는 해저드 위치까지 근거에서 확인될 때만 `true`로 변경합니다.
   거리만 확인되고 배치가 미확인이면 `confirmed: false`를 유지합니다.
4. 해당 홀의 `"sample"` 값을 `false`로 변경합니다.
5. `npm run build`로 빌드가 깨지지 않는지 확인합니다.

## 홀 실사진 교체 절차

실사진은 두 경로로 등록합니다.

1. **공식 코스 가이드 이미지**: `data/courses.json` 해당 홀에
   `"imageUrl": "https://…"` 필드를 추가합니다.
   (공식 홈페이지·코스 가이드북의 홀 전경 이미지 URL 사용. 저작권상 재배포가
   어려운 경우 URL 링크 방식을 유지하고, 불가하면 등록하지 않습니다.)
2. **직접 촬영 업로드**: 촬영 사진을 이미지 호스팅(또는 저장소 `public/holes/`
   하위 파일, 예: `public/holes/solago-라고-1.jpg`)에 올린 뒤,
   - 공용 반영: 해당 홀 `"imageUrl"`에 `/holes/solago-라고-1.jpg`를 입력하고 빌드 확인
   - 개인 단말 표시: 앱 내 '내 메모 → 이 홀 실사진 URL'에 이미지 주소를 입력해
     저장하면 해당 기기의 브라우저(`localStorage` 키 `yardage-img:<club>:<코스>:<홀>`)에만
     저장되어 '실사진' 탭에 표시됩니다.

## 필드 설명

| 필드 | 의미 |
|---|---|
| par | 홀 파(3/4/5). 미확인이면 0 |
| handicap | 핸디캡(1~18). 미확인이면 0 |
| teeBox | 티박스별 거리(m): champion/tour/front/senior/lady. 미확인이면 0 |
| hazards | 해저드 목록: type(bunker/water/ob/rough) + message. 미확인이면 `[]` |
| strategy | teeShot/approach/green 공략 메모. 미확인이면 `""` |
| pinTips | 핀 위치(front/middle/back)별 그린 팁. 미확인이면 `""` |
| diagram | 개략도 렌더용 최소 좌표: dogleg(straight/left/right), hazardSpots[{type,x,y}] (0~100 상대값), confirmed(실측 배치 확인 여부) |
| imageUrl | 홀 실사진 URL(선택). 없으면 '실측 사진 없음' 표시 |
| sample | true=예시, false=실측확인(근거 확보 후에만 변경) |
